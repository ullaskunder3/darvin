# Darvin

A C++ Qt desktop application.

# 🚀 Try Darvin IDE (No Setup Required)

A working beta build of **Darvin IDE** is now available.

You can download the latest release and start coding immediately — no external compiler setup, no manual configuration, and no extra steps.

👉 Download : **Darvin IDE v0.1.1-beta**

---

### What you can do right now

* Write and run **C programs**
* Write and run **C++ programs**
* Create and run **SDL3 applications**
* Compile and execute everything directly inside the IDE

This project is designed to bring back the **"download and start coding"** experience similar to classic IDEs like Turbo C — but built using modern **C++ + Qt**.

> ⚠️ This is still a beta version. Feedback and bug reports are welcome!
